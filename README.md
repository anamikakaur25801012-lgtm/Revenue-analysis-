# 🛒 E-Commerce Pricing & Revenue Growth Analysis

## 📌 Project Overview

The **E-Commerce Pricing & Revenue Growth Analysis** project is an interactive data analytics dashboard developed using Python and Streamlit. The main purpose of this project is to analyze e-commerce sales transactions, understand revenue patterns, evaluate pricing strategies, and identify important business insights.

The project uses an Indian E-Commerce dataset containing **30,600 transaction records and 16 business-related features**. It provides interactive visualizations and analytical reports to help understand customer purchasing behavior, product demand, discount effectiveness, and regional sales performance.

## 🎯 Project Objectives

- Analyze overall e-commerce sales and revenue performance.
- Identify high-performing product categories and regions.
- Examine the relationship between discounts, final prices, and units sold.
- Understand customer purchasing behavior based on age and gender.
- Compare sales performance across different states and geographical zones.
- Evaluate pricing strategies and their impact on revenue.
- Provide meaningful insights through interactive dashboards.

## 📊 Dataset Information

- **Dataset Name:** Indian E-Commerce Pricing & Revenue Growth Dataset
- **Total Records:** 30,600
- **Total Columns:** 16
- **Time Period:** 36 Months
- **Geographical Coverage:** Multiple Indian States and Zones
- **Data Type:** Structured Transactional Data

### Important Dataset Features

- Order ID

## 📈 Dashboard Features

1. **Executive Summary:** Provides an overview of the project, objectives, and important business insights.
2. **Dataset Overview:** Displays dataset records, columns, data types, missing values, and statistical information.
3. **Sales Analysis:** Examines sales performance and revenue trends.
4. **Pricing Analysis:** Studies base prices, final prices, and discount strategies.
5. **Customer Analysis:** Explores customer demographics and purchasing patterns.
6. **Category Analysis:** Compares product categories and their sales performance.
7. **Regional Analysis:** Analyzes revenue and sales across Indian states and zones.
8. **Interactive Filters:** Allows users to filter data by zone, state, category, and other available attributes.

## 🔍 Key Business Insights

- Revenue performance varies across product categories and geographical regions.

- Customer demographics provide useful information about buying behavior.


```bash
cd e-commerce-revenue-analysis
```

```bash

```

### Step 4: Run the Streamlit Application

```bash

```

*Note: Replace `app.py` with your actual Python application filename if it is different.*
